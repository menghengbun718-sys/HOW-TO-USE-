HOW TO USE

Bot control reference for the owner

/message <customer_telegram_id> <text>

Send a message to a customer.

/send <customer_telegram_id>

Choose a customer, then upload a photo or document.

/upload

Submit a file for the owner to approve.

/pending

Review user file submissions.

/delete

Remove a file from the catalog.

/files

List files customers can request.

/view

Choose an HTML file to download.

/previewht

Open HTML in a browser on the bot computer.

/viewht <file_name>

Get an HTML file to open in a browser.

/cancel

Cancel the pending delivery.

/help

Show this message.
